## Stage 2 Detail Sheet — Inventory & Classification (Weeks 1–2)

## Objective
100% of items physically counted, classified and recorded. Items are sorted first, then packed and tagged at package level — nothing moves without a package tag and a contents list. The sequence follows 5S: **Sort → Set in order → Shine → Standardise → Sustain**.

## Daily Plan

| Day | Activity | Output |
|-----|----------|--------|
| D1–D2 | Warehouse sort, then pack and tag packages | WH packages tagged with contents lists |
| D3–D4 | Roofed yard sort — priority: copper cables, tools | RY packages tagged |
| D5–D6 | Open yard sort — heavy items, measure/dimensions | OY packages tagged |
| D7 | Office sort — furniture, cabinets, IT | OF packages tagged |
| D8–D9 | Class A packages sealed, photographed and condition-noted | Photo log complete |
| D10 | Salvage/disposal list compiled and submitted for approval | Salvage list approved |

## Quality Checks

- [ ] Every package has a tag in the `[ZONE]-[CLASS]-PKG-[SEQ]` format
- [ ] Every package has a contents list fixed to it
- [ ] Every item is recorded in the inventory against a package tag
- [ ] Every package has a class (A/B/C/D)
- [ ] Every Class A package is sealed and photographed
- [ ] Inventory spreadsheet is complete and backed up
- [ ] Salvage list reviewed and approved by Operations Lead

## Stage 5 Detail Sheet — Sale & Disposal of Office Furniture (Weeks 3–4)

## Objective
All office furniture sorted, sold or discarded. IT equipment packed.

## Sorting Method

1. **Sort** — tag each furniture item: SELL or DISCARD
2. **Advertise** — post saleable items on marketplace / contact buyers
3. **Scrap** — engage licensed scrap metal collector for discards
4. **IT pack** — disconnect, anti-static wrap, label cables
5. **Filing sort** — contents sorted: KEEP / ARCHIVE / SHRED

## Sale Channels

| Channel | Items |
|---------|-------|
| Online marketplace (Mudah.my, Facebook Marketplace) | Desks, chairs, cabinets |
| Direct to staff | Chairs, small furniture |
| Scrap metal collector | Broken metal furniture, scrap |
| E-waste recycler | Old electronics, non-saleable IT |

## Stage 6 Detail Sheet — Valuable Items Move (Week 4)

## Objective
All Class A items moved first, with maximum security.

## Packing Protocol

1. Item-by-item manifest — every tag recorded in/out
2. Tamper-evident seals on all crates
3. Photograph sealed crate before loading
4. Dual-signature at loading (Security Lead + Logistics Coordinator)

## Convoy Protocol

| Step | Detail |
|------|--------|
| Vehicle | Dedicated secure van or small truck |
| Escort | Security escort vehicle (front or rear) |
| Route | Direct — Pasir Gudang → Masjid Tanah, no stops |
| Communication | 30-min checkpoint calls to PMO |
| Arrival | Security Lead receives, signs manifest |
| Offload | Direct into secure cage, no staging in open |

## Reconciliation

- [ ] Manifest count = load count
- [ ] Manifest count = unload count
- [ ] Secure cage inventory matches manifest
- [ ] Any discrepancies reported immediately to PMO

## Stage 9 Detail Sheet — Loose Items & Consumables Move (Weeks 6–7)

## Objective
All remaining Class C items packed, transported, and shelved.

## Packing Protocol

| Item Type | Packing | Label |
|-----------|---------|-------|
| Fasteners, small parts | Bins with dividers | Category + size |
| Seals, O-rings | Labelled boxes | Type + size |
| Lubricants, chemicals | Original containers + secondary containment | MSDS reference |
| Hand tools | Tool rolls / shadow boards | Tool list inside |
| General spares | Crates by category | Category + tag range |

## Transport Plan

- Multiple vehicle runs as needed (smaller loads)
- Priority order: consumables first, then tools, then general spares
- Each run has a manifest — loaded and unloaded counts reconciled

## Shelving at New Yard

- Items placed into racking by category
- Shelf labels applied (category + date)
- Inventory spreadsheet updated with new location reference
